## 🧩 Sobre o projeto

**FP SELLECTION** é um site interativo que simula um showroom digital de carros, com foco em **design moderno**, **animações suaves** e **experiência do usuário**.
O visitante pode navegar entre diferentes modelos de veículos usando as setas de navegação, e cada transição conta com uma animação dinâmica que dá sensação de movimento realista.

O projeto foi desenvolvido com o objetivo de **praticar HTML, CSS e JavaScript puros**, explorando técnicas de **animação com CSS** e **manipulação de DOM com JS**, além de boas práticas de estruturação e responsividade.

## ⚙️ Funcionalidades

* Navegação entre veículos com setas laterais
* Efeitos de transição animados (entrada e saída dos carros)
* Indicadores e contador de slides
* Design 100% responsivo (adaptado para mobile)
* Transições suaves com `transform` e `opacity`
* Script otimizado para alternância automática (autoplay)

## 🧠 O que aprendi com esse projeto

Durante o desenvolvimento do **FP SELLECTION**, aprimorei conhecimentos em:

* Manipulação do **DOM** com JavaScript puro
* Criação de **animações suaves** com CSS (`transition`, `transform`, `opacity`)
* Estruturação semântica com HTML5
* Implementação de **layout responsivo** com `flexbox` e `media queries`
* Organização de arquivos e boas práticas de projeto front-end
* Depuração e correção de efeitos visuais em transições

## 🚀 Como executar o projeto

```bash
git clone https://github.com/detofollisilva/fpsellection.git
cd fpselection
```

Abra o arquivo `index.html` diretamente no navegador ou use o **Live Server** do VSCode.
